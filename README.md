# Markfly landing page

A small static landing page for Markfly, the native macOS Markdown viewer.

## Preview

From this directory, run:

```sh
python3 -m http.server 4173
```

Then open `http://localhost:4173`. No build step or package manager required.

## Assets

`assets/source/` keeps the supplied originals unchanged. Optimized copies in `assets/` power the page.
